KESSEL THIRD-PARTY TERRAIN DATA NOTICES
========================================

This notice covers the satellite-imagery and elevation-data derivatives shipped in the runtime
payload. Per-file hashes, logical paths, licence IDs, and data-source IDs are recorded in
catalog/runtime_payload.v1.json. Project-authored cropping, grading, detail compositing, class
masks, terrain edits, and format conversion do not make the underlying source data project-owned.

COPERNICUS SENTINEL DATA
------------------------

Data ID: Copernicus Sentinel-2 TCI
Licence ID: copernicus-sentinel-data-rev1
Official legal notice: https://ads.atmosphere.copernicus.eu/licences/ec-sentinel

Required notice for an adapted or modified Sentinel data product:

Contains modified Copernicus Sentinel data [Year]

The exact source scenes and notices are:

Contains modified Copernicus Sentinel data 2024

- Act 1, 2024-01-17: S2B_38UMU_20240117_0_L2A and S2B_38UMV_20240117_0_L2A.

Contains modified Copernicus Sentinel data 2025

- Act 2, 2025-04-02: S2C_33UVU_20250402_0_L2A.
- Act 3, 2025-04-04: S2A_33UVT_20250404_1_L2A.

The high-resolution ground drapes are derivatives of those TCI windows through
tools/worldgen/make_ground_tex.py. The Act 2 and Act 3 ground-class masks are derived from the same
TCI sources. Exact source URLs and research-record locations are preserved in the runtime catalog.

Official AWS Open Data registry: https://registry.opendata.aws/terrain-tiles/
Official Tilezen/joerd attribution:
https://github.com/tilezen/joerd/blob/master/docs/attribution.md
Official Mapzen service/endpoint documentation:
https://www.mapzen.com/blog/terrain-tile-service/

The Garage heightmap and Act 1 height grid are believed to derive from the legacy
stalingrad_100km elevation data and the Mapzen Terrain Tiles Terrarium endpoint. The surviving
development evidence is incomplete: the original fetch date, exact tile keys, and which upstream
layer supplied each Volgograd pixel were not retained. The attribution list below is therefore
useful notice information, but it is not evidence of a redistribution grant for these exact bytes.
Kessel's public-release gate keeps this terrain blocked until provenance and applicable licence
terms are verified.
