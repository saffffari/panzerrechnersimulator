# Finite cigarettes and held flashlight

Implemented in the adaptive-audio checkout. Native scripted input checks pass:15/15 for the cigarette ritual inside and outside, and3/3 for the held flashlight. Source-material readability is confirmed in daylight; cabin hand-item readability remains limited by missing reflected practical-light bounce. These are automated recordings, not a human playtest.

- **C** draws one cigarette and briefly opens the packet, showing its remaining physical cigarettes. C with a cigarette already held toggles packet inspection. The authored starting packet contains 20 cigarettes; another cigarette is not created when re-equipping the same partially consumed one.
- **Hold RMB** brings up and ignites the lighter. **Fresh LMB while RMB remains held** lights the cigarette after the lighter reaches it. RMB alone never lights the cigarette. Releasing RMB puts the lighter away and extinguishes its flame.
- **LMB alone when lit** takes one puff per press. The tip emits continuous smoke; the puff raises the cigarette, brightens its ember, burns additional tobacco, then exhales. Paper recedes from the tip without shrinking the filter. Burn duration 240 seconds and additional 5× burn during 0.85 seconds of inhale are authored gameplay estimates, not a health/combustion model.
- **Q** stows and extinguishes the cigarette while retaining its remaining tobacco. **E** collects a looked-at, reachable world cigarette packet once, removes that same visible world object, and adds 20 cigarettes only if the whole packet fits.
- **F** (legacy **L** also accepted) equips/stows the actual source flashlight body and lens, using the existing finite physical beam and shared source visibility. **Shift+C** retains compass; **M** retains map. Physical extinguisher selection and LMB spray remain available.

`cigarette::State` owns inventory, input edges and elapsed-time consumption. `game::hand_items` masks the local weapon/loader actions only while the item owns the hands, and preserves driving/look and other crew channels. The mounted sidearm is holstered when equipping. Fresh-press guards prevent a held click from transferring between hand item and weapon.

`hand_prop_models` uses the existing owned Pizza cigarette, packet, lighter and flashlight GLBs. There is no newly downloaded or generated asset and no procedural substitute when a hand-prop source cannot load. The actual source cap and paper geometry shorten together. The tiny lighter emitter enters the shared physical light bank through `set_hand_lighter`; only its exact flame mesh is exempted from self-occlusion. It is not a camera fill. Held props join the finite dynamic cabin-shadow caster list. View-local props retain the engine's raster-only/TLAS exclusion convention for split-screen; this is not a general shared-world replication implementation.

`cigarette_vfx` has bounded 192 smoke parents and 24 ash parents with stable fine-particle identities. It updates on every simulation step, then publishes once after catchup. Cabin/exterior classification uses the actual held tip in the same source-derived cabin medium used by weather. Hull-local cabin particles receive zero authored cabin wind; exterior smoke receives current, building-sheltered world wind. This is an air-frame approximation, not ventilation or CFD.
