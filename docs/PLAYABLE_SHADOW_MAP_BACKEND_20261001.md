# Playable geometry visibility and preserved experiment

The default shader backend uses source-geometry shadow maps. `KESSEL_SOURCE_VISIBILITY=maps` selects that default explicitly. `KESSEL_SOURCE_VISIBILITY=portable` retains the source-triangle BVH and optical diagnostics as an experimental reference. The default does not compile traversal WGSL or register/refit/upload scene BLAS/TLAS payloads. Existing small placeholder buffer bindings remain to avoid a second GPU resource ABI.

This choice follows actual hardware evidence: full MAIN MSAA renders produced NVIDIA Xid 109 context-switch timeouts; the isolated 512-ray GPU test passed, and an AA-off whole scene completed but showed unsupported optical connections. This does not prove a unique driver/compiler cause. Neither experimental result is accepted as a playable renderer.

All 32 admitted point sources receive six source-geometry depth faces. Named lamp registrations only identify the emitter mesh to exclude; they do not decide whether a light shadows. The 5 mm numerical near plane remains. Each far plane now encloses the loaded source/receiver bounds and camera far/medium support, rounded outward; no 8 m source cutoff or missing-registration all-lit branch exists. Linear depth and receiver-plane PCF are retained. A missing map or out-of-coverage receiver produces an explicit diagnostic.

Environment transport uses the unchanged physical 32-direction probe radiance. Each direction has a 384-pixel fine local tile and a coarse tile fitted around loaded geometry plus full camera/medium support. Two further tiles capture the actual key-light direction. Both cascades participate; outside the local footprint is covered by source geometry, not open-sky fill. Terrain and view-local opaque meshes cast; mirrors block straight direct connections. Static terrain/modules are cached separately from moving loose meshes. Fine snow/fire/smoke carriers do not enter the opaque caster cache. Existing weather/cabin interval separation, Beer extinction, source strengths, native fine VFX, MSAA and final native Bayer8 are unchanged.

Finite-map limitations are explicit: global coverage can be very coarse in a large map; comparison bias is 0.35 local texel / 0.65 coarse texel, so sub-texel occluders and contacts can be missed. The sun direction is quantized to 1e-4 components to avoid sub-texel ephemeris cache invalidation. Grass alpha cards and transient particle carriers are excluded as solid casters. Transparent panes/lenses are straight-through for these visibility maps: no Fresnel, glass absorption, refraction or general optical relay connection is modeled. Reflected indirect illumination is absent. These are source-based raster approximations, not claims of exact light transport. Capture receipts name the actual selected backend and its limits.

Validation: `cargo test --release --test stylized_raster` passed 18/18, including composed mesh, smoke and particle shaders for both backends. The sealed candidate3 CPU run passed 69/69 selected tests (one separate GPU test ignored), including 15 point-shadow, four sky-visibility, two projected-coverage and one native-AA tests. Native source-map/MSAA frames completed without the earlier experimental magenta/hang. Three bounded performance changes reduced the same 60-frame native800 render benchmark from 143.04 ms mean to 33.31 ms mean; p99 remains 117.29 ms. This timer excludes game simulation and is not an interactive playability result. The final image is byte-identical to candidate2 and differs from the baseline in six of 360,000 pixels (maximum channel difference 11/255). See `RENDERER_PERFORMANCE_20261001.md` for exact scope, evidence and remaining limits. Motion/combat acceptance remains with the root-owned review captures.
