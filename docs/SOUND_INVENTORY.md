## Sourcing (commercial-safe for the Steam release)

1. **Sonniss GDC bundles** (sonniss.com/gameaudiogdc) — pro libraries, royalty-free
   commercial, no attribution. Multi-GB archives; best bulk source for war/weapons/vehicles.
2. **freesound.org filtered to CC0** — the audition pipeline here. CC-BY is fine too
   (needs a credits list); NEVER CC-BY-NC.
3. **BOOM Library / 99Sounds / Zapsplat / Pixabay free packs** — commercial-ok freebies.
4. **Internet Archive** — WWII-era recordings, check per-item license.
5. ⚠ **BBC Sound Effects archive** — non-commercial license: reference only, never ship.
6. Paid single libraries if a hero sound resists free sourcing (real T-34/Tiger recordings
   exist on the A Sound Effect marketplace) — the engine loop proved one great recording
   carries an entire system.

License record: keep `assets/sfx_auditions/INDEX.md` (source URL per pick); on greenlight,
download the ORIGINAL from the source page, note the license next to the entry.
